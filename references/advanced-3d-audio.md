# 莱茵生命进阶：3D / 卡片 / 音效 / 字体 / 视频渲染

提炼自 RhineLabUI（MIT）、rhine-lab-art、Multiplane（Apache-2.0）三个开源项目与官方 PV《莱茵生命：访问》的实测参数。出处见 `sources.md`。

## 一、3D 档案阵列（Three.js 级别的参数，DOM/CSS 可近似）

### 几何与布局
- 相邻通道中心距 **5.2** 世界单位；卡片宽 5、高 3.7，行距 0.62；档案端面深约 0.31
- 关键高度：悬停浅抬起 **0.4**；点击后详情升至 3.35（交互模式 **4.05**）；悬停额外 +0.28（约 200ms 显现）
- 旋转限幅 ±0.8 弧度；返回时**先在原高度转正再下降**
- 呼吸起伏：停止操作 2.5s 后渐入；8s 与 13s 双周期叠加，最大单向位移约卡片高 2.8%，相邻卡片错相

### 波浪动效（选中卡片的标志性效果）
- 选中瞬间卡片抬起与**阵列波浪同时开始**：阻尼速率 4.2、幅度系数 0.8、起势 0.2s，完整正负波谷
- 非选中列保留 25% 以上"肩部波幅"；两侧卡片在回传波后继续起伏，按距选中位置的距离延迟并衰减

### 阻尼与惯性
- 轨道与升降用**保留速度的临界阻尼**；快速重新选中时旧卡独立归位、新卡接续运动
- 拖动：10px 起拖阈值；松手保留实际速度减速滑行；按住滑行中的阵列立即停止

### 镜头（相机）校准参考值
- 阵列远景：方位角 59°、仰角 19°、长焦压缩透视（取景范围 7.33）
- 详情特写：距离 72 的长焦，near 从 0.1 改 5（避免深度抖动）、far 300
- 360° 查看器：初始位 (7.2, 3.8, 12)，缩放 5–28；平移/缩放 200–250ms，复位 560ms 减速曲线走球面短路径

### 材质（玻璃质感要点）
- 磨砂盖板 roughness 0.48 → 清晰 0.025，**边界自顶向下过渡**，中间羽化宽度为高度的 24%（原片 38.84s 开始、39.56s 结束）
- 灯光基准：曝光 1.0、环境 0.52、暖白主光 1.7（位置 -8,14,4）、补光 0.3、半球 0.5
- 阵列盖板加少量暖色吸收；斜面和背板偏浅香槟色

### CSS/DOM 近似方案（无 Three.js 时）
- 卡片容器 `perspective: 1200px`，卡片 `transform-style: preserve-3d`
- 悬停：`translateY(-8px) rotateX(±4deg)`；选中：`translateY(-28px)` + 兄弟卡片按距离 `translateY(±(6~2px))` 制造波浪（JS 按 `distance` 计算延迟与幅度，阻尼 4.2 的临界阻尼可用 `spring(t,14)` 缓动近似）
- 阵列呼吸：`animation` 双周期 `8s/13s` 正弦叠加、幅度 <3%、相邻 `animation-delay` 错相

## 二、卡片/终端文字效果

### Rolling Number（滚动数字/文字）
- 编号滚动 **460ms**，固定 X- 前缀 + 三位前导零；标题模糊强度 0.2、固定向上滚动；字数变化由宽度弹簧处理
- 历史方案（可参考）：变化间隔 <240ms 触发短促闪动，140ms 黑色横条，停止 260ms 后 180ms 短闪落定
- 页脚数字时钟：时/分/秒**独立滚动**（各位数字独立 odometer）

### 解密动画（模型与正文同步）
- 对角解密线：向中央延伸（34.24–36.04s）→ 保持完整（→37.72s）→ 收束（→38.84s）→ 透明；交互详情压缩至约 3.63s
- 盖板自上而下由磨砂变清晰；右侧文档遮挡条同步退开露出正文
- CSS 近似：两条对角线 `scaleX` 相向展开 → `backdrop-filter: blur()` 从 8px 过渡到 0（配合 `mask-image: linear-gradient` 自顶向下扫过）→ 正文区宽度展开

### 开场序列（boot，深色终端 → 白场 → 阵列）
- 流程：黑底 → 三行文字错峰出现（间隔约 80ms，先加速后减速）→ 权限圆环（内外环独立变速、内环与橙点减速、黑白端点同步缩小）→ 两侧小圆反向旋转 → Logo 连续笔画绘制 → 身份验证/授权扫描 → 欢迎页 → **白场** → 阵列从左滑入
- 关键手法：空间运动用**单调三次插值（无过冲）**；离散闪切保持 25fps 时间码；Logo 缺口沿轮廓移动而非整枚闪烁
- rhine-lab-art 的深色开场：整体深色、止于欢迎页，主资源就绪且欢迎帧停稳后约 1.5s 淡入主场景；"减少动态效果"偏好直接显示欢迎页

## 三、声音设计（RhineLabUI 体系）

### BGM
- **三轨循环配乐**，随场景四阶段（开场/阵列/详情/查看器）动态调整三轨比例——不是单曲循环，而是分层渐入渐出
- 浏览器策略：需一次用户手势后才启动 AudioContext；音乐/音效独立开关、独立音量

### 交互音效
- 共 **17 类**交互音；区分"玻璃碰触"（切档轻碰、抽取余音、归位落定——玻璃共鸣）与"电子反馈"（系统操作）两大类
- **逐字输入音**：三个 38ms 短音轮替（源自原 PV 6.864–6.986s），输入最短间隔 24ms
- 自制音效方案：WebAudio 合成——玻璃轻碰 = 高频正弦短音（2~4kHz，8~20ms，快速衰减）+ 少量混响；电子反馈 = 方波/锯齿短脉冲（120~800ms 长的 UI 音用 40~80ms）；机械归位 = 低频 thump（150~250Hz，30ms）+ 高频 tick

```js
// WebAudio 合成点击音（无版权风险，替代采样）
function rlSfx(kind = "glass", ctx = null) {
  ctx ??= (window._rlAC ??= new AudioContext());
  const t = ctx.currentTime;
  const o = ctx.createOscillator(), g = ctx.createGain();
  const P = { glass: [3200, "sine", 0.02, 0.12], ui: [640, "square", 0.045, 0.06], thump: [190, "sine", 0.05, 0.2] }[kind];
  o.type = P[1]; o.frequency.setValueAtTime(P[0], t);
  o.frequency.exponentialRampToValueAtTime(P[0] * 0.6, t + P[2] * 4);
  g.gain.setValueAtTime(P[3], t);
  g.gain.exponentialRampToValueAtTime(0.0001, t + P[2] * 6);
  o.connect(g).connect(ctx.destination); o.start(t); o.stop(t + P[2] * 6);
}
```

## 四、字体体系（补全）

| 用途 | 字体 | 备注 |
|---|---|---|
| 终端/品牌展示字 | **Novecento Sans Wide**（Normal/Bold/DemiBold） | RhineLabUI 开场中央大字、rhine-lab-art 标题；Wide 宽体是"终端铭牌"感的关键；注意其为商业字体，开源项目需自行授权或用固定字形轮廓替代 |

- 品牌排版精确值（1080p 基准，源自原片 13.48s）：品牌容器左 59px、上 114px、宽 270px；第一行 44px/行高 48px/字距 2.5px；第二行 19px/23px/600/0.65px；第三行 35px/40px；OS 在 270px 容器右端对齐、字距 3px
- 开场大字：Novecento Sans Wide Bold，处理提示 21.35px、左上 RHINE LAB DemiBold 50.75px/字距 1px

## 六、UI 过渡时长表（RhineLabUI 实测）

| 过渡 | 时长 |
|---|---|
| 详情层进出 | 180ms |
| 弹窗入/出 | 300ms / 200ms（入场位移 12px、退出 8px） |
| 页签正文淡入 / 下划线 | 150ms / 180ms |
| 收藏颜色反馈 | 220ms |
| 查看器淡入 | 320ms（模型载入后 380ms 从 0.97 倍展开淡入）；退出 220ms |
| 滚动编号/标题 | 460ms |
| 底部刻度伸缩 | 400ms |

原则：**进入中途关闭时从实际状态接续**，永不跳变归零；全部过渡遵守系统"减少动态效果"设置。

## 七、Multiplane：HTML→视频渲染管线（附属工具）

- 用途：把"莱茵生命动效"做成视频时，用普通网页写镜头（`render(t)` 纯时间函数），无头 Chromium 逐帧截图 + FFmpeg 合成，确定性可验证（`verify`）
- 关键能力：运动模糊不跨硬切（`cuts` 声明）、三维层累积景深（`multiplane/three`）、胶片颗粒后期、静帧/联系表输出
- 典型用法：`npx multiplane render shot.html --motion-blur standard --grain`；或静帧 `npx multiplane stills shot.html --at 3.2,7.8`
- 设计参考：镜头页面直接套用本 skill 的 starter token，即得"代码化的莱茵生命短片"
