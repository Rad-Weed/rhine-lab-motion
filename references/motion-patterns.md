# 莱茵生命动效模式库（motion patterns）

12 种核心动效模式。参数均提炼自同人逐帧渲染短片（laiyin-video）的实现，与官方 PV 气质对齐。每条给出机制与实现要点，starter 模板（`assets/starter/`）内含可运行版本。

## 1. 乱码解码显现（decode / scramble）——文字入场首选

- 机制：按进度 `p` 从左到右"解锁"字符；未解锁的尾部显示乱码，乱码每 **32ms** 换一批。
- 参数：乱码字符集 `A-Z0-9#%&*+=/<>`；尾部长度默认 3；乱码字符由 `hash2(i + seed*31, tick)` 决定（`tick = floor(t/0.032)`），保证可复现。
- 适用：英文标签、编号、章节代号。中文不用乱码（见模式 3）。

```js
const GLYPHS = "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789#%&*+=/<>";
function decodeText(target, p, seed = 0, tail = 3) {
  const t = Date.now();
  const tick = Math.floor(t / 32);
  const n = target.length, solved = Math.floor(p * n);
  let out = target.slice(0, solved);
  for (let i = solved; i < Math.min(n, solved + tail); i++)
    out += GLYPHS[Math.floor(hash2(i + seed * 31, tick) * GLYPHS.length)];
  return out;
}
// 用 requestAnimationFrame 驱动 p: 0→1（outCubic，约 0.6~0.9s），p>1 后锁定全文
```

## 2. 打字机 + 块状光标

- 机制：`floor(p*n)` 个字符逐个出现；光标是**实心矩形块**（荧光绿 `#b9e432`），宽 `0.55em`、高 `0.95em`，贴在最后一个字符后。
- 适用：命令行式日志、正在加载的语句。

## 3. 中文字符滑入（CJK 不做乱码）

- 机制：汉字从左到右逐字**淡入 + 上滑**（上滑量 `0.25em`），用 `smooth` 缓透明度、`outCubic` 消位移；前半程颜色从弱化灰 `#8b8882` 渐变到墨色，制造"解码完成"感。
- 适用：中文标题、字幕的入场。

## 4. 分级入场（staggered reveal）

- 机制：一组元素用同一进度 `p` 错峰触发：`q1 = p*3`, `q2 = p*3 - 0.5`, `q3 = p*3 - 1.1`，各自再过 `outCubic(clamp(q))`。
- 节奏：整组控制在 0.6~1.2s 内完成，间隔均匀偏递增（不是等距）。
- 适用：数据行、日志列、卡片墙——所有"列表类"内容入场。

## 5. 里程计数字（odometer）

- 机制：数字像机械里程计逐位滚动；**每位只在低位进位时才滚动**（不是全体同时滚）。行高 `1.0em`，字符宽 `0.98em`。
- 简化版（odometerStep）：旧值→新值整体 `outCubic` 滚动，行高 `0.95em`。
- 适用：计数器、档案编号、百分比。

## 6. 警告板（WARNING plate）

- 机制：橙色括号条从中心向两端展开（`outQuart`，`p*2.2` 定宽）→ 警告三角（边 17px、线宽 2.4px）落下 → "WARNING" 30px/字距 6px → 日志行从 `p>0.45` 起逐行出现；**末行橙色高亮 + 右侧 10×10 方框以 4Hz 闪烁**（`floor(t*4)%2`）。
- 伴随：配乐"转闷"（低通滤波）、背景压暗。适用于封锁/异常场景。

## 7. 进度绘制（线条按进度生长）

- 机制：线段、环、边框不是淡入，而是**从起点画到终点**。SVG 用 `stroke-dasharray/stroke-dashoffset`；Canvas 用 `setLineDash` 按路径长度绘制。
- 旋转权限环：主弧从 -90° 起转（角速度 0.6 rad/s，弧长 86%×2π×p，线宽 2）；内双弧半径 0.34r **反向**旋转（1.4 rad/s，线宽 1.2）；2 个轨道点（0.66r，橙色）。
- 适用：分割线、权限环、进度条、加载指示。

## 8. HUD 框架（chrome layer）

一层贯穿全程的界面框架，先于内容出现、后于内容消失：

- 页眉三行错峰解码（p>0 / 0.25 / 0.45 时各自开始）：左 RHINE LAB、中 SYNTHESIZE INFORMATION（`fitTracking` 铺满）、右 ANALYSIS OS（ANALYSIS 用 300 字重 + OS 用 700）。
- 页脚：右下角 24×5 横线 + "POWERED BY RHINE LAB"。
- 左侧竖轨线 + lime 标记块；右上角步骤指示器（5 节点：当前节点外环 9px/线宽 2.4 + 内点 3.2px，非当前 4px，标签 11px mono/字距 2.4）。
- 双语字幕板：中文 23px/500 + 英文 11px/600，深色场景垫黑色板（`#101112`）。
- **实现要点**：HUD 是独立图层（position: fixed / 覆盖层），与内容层解耦，透明度与解码进度独立驱动。

## 9. 档案元素组件

- **chip 胶囊**：黑底白字（`#101112` 底 + 反白字 13px/600/字距 0.8），高 1.45em、内边距 0.6em；**宽度先展开、文字后出现**（p>0.6 才显示文字）。
- **取景框四角 corners**：18px 角线，线宽 2——出现在任何"被观测/被记录"的内容四周。
- **bracket 括号**：34px、线宽 7，用于强调块左右。
- **机密照片 classified**：半调网点人物剪影（点阵步长 w/34）+ 橙色 "PHOTO CLASSIFIED" 标签（11px/700/字距 1.5，标签高 19px，位于 0.8h）。
- **涂抹条 redacted**：橙色实心条覆盖敏感文字，涂抹条高约 0.72em。
- **callout 标注**：锚点圆点（5px）→ 折线引导线（线宽 1.6，随 p 展开）→ bracket + chip + 标题（29px/700）+ 副文（13px）。
- **身份块 identity**：黑徽章块 112×78（内含 ∞ 宽 74 + "RHINE·LAB" 6px/字距 3）+ 职务 24px + 姓名 46px/800/字距 -0.5 + 底线（宽 620、高 3）。

## 10. ∞ 标记动效

- 机制：双环按**笔顺**绘制（`setLineDash` 按路径长 2813/环），描边宽/画布 = 100/1200；+/− 符号在环画完的 `p 0.55→1` 区间浮现；− 符号只做水平缩放（`scaleX`）入场。
- 适用：品牌落版、加载标识、徽章。SVG path 双环 + `stroke-dashoffset` 即可复刻。

## 11. 转场（shot transitions）

- **故障/撕裂 glitch**：RGB 通道错位 + 水平条带撕裂 + 抖动，持续 2~4 帧（@30fps），用 `hash` 噪声驱动条带位置与偏移量，每帧重掷。
- **硬切混合**：切点处前后两个画面短暂叠加（交叉溶解极短，≤3 帧）或直接硬切——莱茵生命的切点是"砸"出来的，不用长溶解。
- **卡点**：转场中心对齐拍点（112 BPM 网格）。
- **信号入侵叙事**：授权比对 → 机密档案（CLASSIFIED 涂抹、半调照片）→ 封锁 WARNING（压暗 + 4Hz 闪烁）→ 恢复公共频道。这套三段式是标志性的情绪曲线。

## 12. 环境动效（idle motion）

- **烟雾漂移**：黑色烟雾块在深色板上以 `sin(t*0.17)*0.03w` / `cos(t*0.13)*0.03h` 低频漂移，透明度 0.55。
- **网格微动**：方格/蜂窝网格整体缓慢偏移，或跟随视差。
- **套准点**：角落小圆圈（半径 0.021w）常驻，偶尔闪一下 lime——"设备在线"的呼吸感。
- 原则：idle 动效全部低频（<0.2Hz）、低幅度（<5% 位移），绝不抢内容。
