# 官方站点实测：把「官方页面」当作第一手参照

> 采集时间 2026-10-22，方法见文末「复测方法」。所有色值、字族、时长都是从线上 CSS / 渲染后的计算样式里读出来的，不是凭印象概括。
> 本文只记录**可执行的设计事实**（色值、字族、字阶、时值、版式母题），用于校正本 skill 的判断标准。

## 〇、为什么单列一篇

同人复刻（laiyin-video / RhineLabUI / rhine-lab-art）给我们的是**动效与 3D 的实现参数**；
官方站点给我们的是**取舍纪律**——什么该省、什么必须硬边、哪里允许一块纯色压住画面。

两者互补：前者告诉你怎么动，后者告诉你什么不该动。

## 二、实测色板

### A. 站点模式（`ak.hypergryph.com`，深色）

| 角色 | 值 | 说明 |
|---|---|---|
| 主强调（青） | `#18d1ff` | CSS 中出现 42 次，**唯一的品牌高亮色**：active 导航、页码大数、小箭头 |
| 黑场 | `#000` / `#121212` / `#1d1f20` | 页面底与卡片底，纯黑用于全屏 hero |
| 深板 | `#242424` / `#272727` / `#292929` / `#333` | 次级面板、悬浮条 |
| 文字 | `#fff` / `#d2d2d2` / `#ababab` / `#8d8d8d` / `#585858` | 五档即止，与我们的灰阶纪律一致 |

**结论**：官方深色站点只用 **1 个高饱和色**。这印证了本 skill「橙 ≤3% 面积」的纪律，也给出了第二种合法方案——若要更"官网"，把高亮换成青，但**仍然只有一个**。

### B. 档案模式（`terra-historicus`，纸）

| 角色 | 值 | 说明 |
|---|---|---|
| 纸白 | `#f7f7f7` | 文档/画布底（比我们的暖纸 `#f6f3eb` 更冷、更中性） |
| 黑阶 | `#212121` / `#2a2a2a` / `#313131` / `#434343` / `#505050` | 五档黑，对应我们的 ink/ink-2/mute |
| 朱红 | `#b0243b`（12 次）/ `#cd1a37` | **印章、下划粗线、按钮、页码控件** |
| 警示黄 | `#fff000` | 仅高亮标记，面积极小 |
| 遮罩 | `rgba(0,0,0,.35/.5/.7/.8)` | 模糊背景前的压暗层，四档 |

**与本 skill 的关系**：我们用「印刷橙 `#e9521c`」做标注，官方纸质档案用的是「朱红 `#b0243b`」。
分色规则（0.17.0 起）：

- **橙 = 运行态**：当前项、警告、进度、机械交互
- **朱红 = 归档态**：印章、批注、下划、卷宗号、已阅标记
- 二者不同版同现；同一版面只允许其中一种是"有面积的色块"

## 三、官方字体栈（实测 `font-family`）

两站都是**字重分文件**（`SourceHanSans-Bold` 这种写法），说明他们直接加载多个静态字重，而不是靠 `font-weight` 合成。

| 站点 | 实测字族 |
|---|---|
| ak 官网 | `SourceHanSans-Bold / Medium / Regular / Heavy`（中文）、`Bender-Bold / Regular`、`Oswald-Medium / DemiBold`、`Novecentosanswide-UltraBold / Bold / DemiBold / Medium` |
| 泰拉记事社 | `SourceHanSansCN-Bold / Regular / Normal / Medium`、`Geometos`、`Gilroy-ExtraBold`、`SimHei` 兜底 |
| 鹰角官网 | `Noto Sans SC`、`SourceHanSans-Regular / Bold` |

角色分工（可直接照搬）：

- **CJK 正文/标题**：思源黑体（Source Han Sans SC）——就是 MiSans 的最佳免费等价物
- **拉丁大标题 / 编号**：Novecento Sans Wide（宽体、极适合 `00 / 05` 这类页码与 `ARKNIGHTS` 式字标）；免费替代 `Oswald`（窄）或 `Archivo Expanded`
- **拉丁小字/数据**：Bender（工程感几何无衬线）→ 免费替代 `Roboto Mono` / `IBM Plex Mono`
- **纯几何展示**：Geometos / Gilroy-ExtraBold → 免费替代 `Poppins`（同几何骨架）

> 授权：Novecento Sans Wide、Bender、Geometos、Gilroy 均为商业字体。**本 skill 只借"角色分工"，不打包字体文件**；产出里用免费替代，并在 README 注明。

## 四、字阶与时值（实测）

### 官方字阶（rem = 16px）

`12 / 14 / 16 / 18 / 20 / 24 / 32 / 40 / 60 / 112 px`
= `.75 / .875 / 1 / 1.125 / 1.25 / 1.5 / 2 / 2.5 / 3.75 / 7 rem`

- 最常用：`.875rem`(14) 与 `1.25rem`(20)
- 显示级：`3.75rem`(60)、`7rem`(112) —— **112px 是官方大锚点的量级**
- 大字字距 `letter-spacing:-.05em`（出现 10 次，出现在显示级标题上）
- 小字字距：`2px`（导航）、`1px`（标签）、`.5em`（竖排/装饰）、`.1em`（胶囊）

对照本 skill：我们的大锚点用 1180 版心，112px 大约占版心 9.5% 宽——正好是"一个字撑起一页"的比例。**版面锚点小于 80px 时不叫锚点。**

### 动效时值（实测 `transition`）

| 时长 | 用途 | 出现频次 |
|---|---|---|
| `.3s` | 默认微交互：opacity / color / background / transform | 最高（两站第一） |
| `.4s cubic-bezier(.22,.58,.12,.98)` | 需要"手感"的位移+淡入（泰拉记事社） | 少数 |
| `.6s` | 面板展开、图片显影 | 中 |
| `1s` | hero 级转场、整屏切换 | 少 |

**重要细节**：官方把 `visibility` 和 `opacity` 绑在同一时长上——`transition:opacity .3s,visibility .3s`。这样元素隐藏后不再吃事件，也不会在动画中闪。我们此前的入场动画没有统一这一条，0.17.0 起写进规范。

## 五、12 个可直接落地的版式母题

每条都给了"怎么做"，不复述画面。

1. **装载屏 chrome**（ak 官网首屏）
   全屏纯黑 + 一条 1px 发丝线横贯上下（距视口边约 40px），四角各一枚短刻度；左下 `© HYPERGRYPH`（等宽，字距 .18em）；中央 logo 下方一条随进度延伸的细线；底部左 `>> LOADING - 0%`，右 `ARKNIGHTS /// https://ak.hypergryph.com/`。
   → 这就是我们终端开场的官方版，**改用"一条线 + 四角刻度"替代满屏噪点**，静得多，也更像工程设备。

2. **双语导航**
   英文全大写 11–12px / 字距 2px / 字重 700；中文 9–10px 紧贴其下，字距 normal，颜色降到 60% 灰；active 项变青并加一条 2px 下划线，长度等于英文词宽。
   → 我们此前的导航只有英文，中文缺失会让"档案感"变成"外国网站感"。

3. **巨型字裁切**
   把英文词标做到 300px 以上，字号按视口宽算（`font-size:min(28vw,420px)`），让它**出血到画面外**，透明度 8–14% 或实色压在影像上；再叠一个词的第二层（错位 40–60px、不同透明度）制造套印。
   → 我们只在封面试过；正文跨页的"章节墙"也可以用它。

4. **纯色几何块压影像**
   一块硬边矩形（无圆角、无渐变、无阴影），高饱和单色，直接压在照片/插画上，覆盖 15–30% 画面；块内可放反白小字。这是官方最"大胆"的一招，但**一页只用一次**。

5. **模糊背景 + 前景纸卡**
   背景取当前内容的封面做 `blur(28px) brightness(.55)`；前景是清晰卡片，卡片外加 1px 白色半透明边框与四角短角标；卡片下方留一条 8px 的白色 caption 条。
   → 用于"打开一卷档案"的详情页，比纯纸面更有现场感。

6. **标题下固定长度分隔线**
   H1 之下一条 1px 线，长度固定（约 40 字符宽或 320px），不随标题长度变化，末端可加 6px 方块。

7. **章节胶囊网格**
   `1px solid rgba(255,255,255,.35)` + 无圆角或 2px 圆角，2 列等宽，内边距 8px 12px，编号在左（等宽 10px，60% 灰），标题右对齐；有未读/更新时左端加一枚 8px 沙漏或方块。
   → 用于目录页、索引页，比我们的"点线目录"更耐看。

8. **唯一实心 CTA**
   整页只有一个实心按钮（朱红或青），其余全是描边或纯文字。按钮无圆角、字距 .12em、高度 36–40px。

9. **索引卡竖排露边**
   右缘一列卡片，垂直堆叠，每张只露出 68–80px 高，露出的部分是缩略图 + 编号 + 2 行小字；hover 时整张左移 12px。这是"卷宗抽屉"的界面化。

10. **桌面透视纸**
    纸张以 `rotate(-8deg)` + `perspective(1200px) rotateX(6deg)` 躺在桌面上，投影 `0 30px 60px rgba(0,0,0,.35)`；纸上还压着回形针/长尾夹的实物阴影。
    → 我们的 `scene3d` 是"悬浮阵列"，这一招是"落在桌上"，两者可在不同页面并存。

11. **页码指示 `00 / 05 + 段落名`**
    大数字用宽体字（60–112px），斜杠与总数用 12px 灰字，段落名在下方 9px / 字距 .2em 全大写。数字用 tabular-nums。

12. **右侧白色功能条**
    白底黑字、无圆角、行高 34px，图标固定 18px 在左，文字 12px，行间 1px 灰线；整条只有 1px 白边不加阴影。用于下载/入口区。

## 六、声音：官方页面默认是静的

ak 官网顶栏右侧有一枚**音量开关**，说明音频是"用户主动开启"的能力，而不是自动播放；页面本身没有常驻 BGM。
→ 结论写进规范：**默认静音，首次交互后再允许出声**；任何自动播放的循环音都必须挂在显式开关上。我们此前的"初次进入就有音效"在官方逻辑里是不成立的。

## 八、复测方法（下次更新时照做）

```bash
# 1. 拿页面，找出真正的 CSS
curl -sL -A "Mozilla/5.0" https://ak.hypergryph.com/ -o ak.html
grep -oE '<link[^>]*href="[^"]+\.css"' ak.html

# 2. 官方 CDN 返回 gzip，必须解压后再统计
curl -sL "<css-url>" -o a.css && gzip -dc a.css > a.txt

# 3. 统计色值 / 字族 / 字阶 / 时值
grep -oiE '#[0-9a-f]{3,8}' a.txt | tr 'A-F' 'a-f' | sort | uniq -c | sort -rn | head -20
grep -oiE 'font-family:[^;}]+' a.txt | sort | uniq -c | sort -rn | head -10
grep -oiE 'font-size:[^;}]+'   a.txt | sort | uniq -c | sort -rn | head -10
grep -oiE 'transition[^;}]{0,60}' a.txt | sort | uniq -c | sort -rn | head -10
```

SPA 的正文是 JS 渲染的，`curl` 只能拿到壳。**要判断版式必须截图**：`puppeteer-core` 驱动本机 Edge，`defaultViewport 1440×900`，`domcontentloaded` 后等 3–13s（ak 官网的装载屏约 10s 才过），再 `screenshot`。
