# 编辑设计系统（Editorial System）

> 这份文档是本技能的核心。若只读一份参考，读这份。
> 之前的版本把莱茵生命拆成"色板 + 动效模式 + 组件"，结果做出来是**组件展台**：动效像、音效像，但版面不像档案。
> 真正的精髓在**编辑设计**：网格、字阶、构图纪律、印刷工艺痕迹，以及"一页只讲一件事"的克制。

---

## 0. 命题

**莱茵生命 = 一册被投影到屏幕上的印刷档案。**

| 层 | 是什么 | 承担什么 |
|---|---|---|
| 纸（substrate） | 米色胶版纸、纤维噪声、页边阴影、装订孔 | 物质感与"这不是网页"的第一印象 |
| 墨（content） | 单黑文字、1px 细线、45° 网点图版 | 信息与精度 |
| 专色（annotation） | 橙 `#e9521c`，面积 ≤3% | 标注、索引、印章、警告 |
| 屏幕（time & light） | 显影、压印、翻页、光标坐标 | 只追加时间与光，不追加装饰 |

判断标准：**把颜色全部去掉，页面是否仍然像一份档案？** 不像，就是靠颜色在撑，跑偏了。

## 1. 网格与基线

```
内容宽   1180px        页边距 56px
栏数     12            栏距 20px（= 1 栏 ≈ 70.7px）
基线     8px           正文行高 24px = 3 基线
默认分栏 7 / 5（正文 7 栏｜图版或边注 5 栏），可 6/6、8/4
```

- 所有纵向间距取 **8 的倍数**（8/16/24/32/40/56）。
- 版面内容 **不得贴到页边**：文字距页边 ≥56px；只有图版、色条、黑版允许出血。
- 每个版面可被"网格叠加"验证（演示页按 `G`）：12 栏半透明 + 8px 基线，用来自查而不是装饰。

```css
:root{ --page-w:1180px; --mar:56px; --gutter:20px; --baseline:8px; }
.g{display:grid;grid-template-columns:repeat(12,1fr);gap:var(--gutter)}
.g > *{min-width:0}                       /* 关键：否则长数字/长串会把栅格撑破 */
.c1-7{grid-column:1/8}  .c8-12{grid-column:8/13}
.c1-12{grid-column:1/13}                   /* 跨栏元素（表格、图表）必用 */
```

> 踩过的坑：漏定义跨栏类 → 图表被塞进单栏 70px，SVG 被等比缩成一条竖线。任何"图表塌成一条"先查这一条。

## 2. 字阶与字距（光学曲线）

| 角色 | 字号 / 行高 | 字距 | 用途 |
|---|---|---|---|
| 封面大字 | clamp(58px,10.4vw,148px) / .90 | **-0.035em** | 一页一次，机构名 |
| 版面大锚点 | clamp(38px,5.2vw,62px) / 1.02 | -0.02em | 章节标题、海报字 |
| 描边数字 | clamp(60px,7vw,104px) / 1 | -0.04em | 索引总数、页码 |
| 主读数 | clamp(46px,7vw,92px) / 1 | -0.02em + tabular | 一个大数，配单位上标 |
| 小标题 | 27px / 1.25 | +0.01em | 正文标题（中英双语，英文另起 10px 大写） |
| 正文 | 13px / 1.98 | +0.02em | 双栏正文，色 `#3c3c36` |
| 图注 | 10px / 1.75 | +0.16em | 大写、等宽、`#7d7a72` |
| 微排版 | 8.5px / 1.5 | +0.24em | 元数据、页脚、编号 |

规则：

1. **字号越大越收紧，越小越放开**（上表即曲线；14px 附近是 0 点）。
2. 数据一律 `font-variant-numeric: tabular-nums` + 等宽；小数位固定（`0.7731` 不要变 `0.77`）。
3. 中文标题字距 +0.02~0.05em；中英混排时英文与中文之间留 0.25em（用 `gap` 或空格，不用 `margin` 拼）。
4. 首字下沉 46px / .88，仅正文首段一次；不要每段都下沉。
5. 英文大写**永远带字距**；不带字距的全大写 = 廉价。

## 3. 构图六律

1. **一页一锚点**：每版面只有一个 60px 以上的元素（大字 / 大数 / 图版 / 黑版）。出现两个大元素 = 没有重点。
2. **尺度对比 ≈ 10:1**：锚点 92px vs 正文 13px。中间尺寸（20–40px）只用于标题，不要滥用。
3. **静区 ≥40%**：版面必须有成片空白，且空白要"成块"，不是均匀撒开的间隙。
4. **节奏 密→空→密**：相邻版面交替密度。纸白正文页之后接整版黑海报，是最有效的一次呼吸。
5. **非对称**：默认 7/5；不要居中对称构图（除了封面机构名与 ∞ 落版）。
6. **注释即纹理**：脚注、边注、校改栏、图注编号不是附属品，是版面灰度的一部分。每页至少 2 条注释。

## 4. 印刷件目录（13 种，任一版面 ≥3 种）

| # | 印刷件 | 参数 / 做法 | 位置逻辑 |
|---|---|---|---|
| 1 | 裁切标记 crop marks | 16px 双线 L 角，`opacity .55` | 四角内缩 14px（出血位） |
| 2 | 套准靶 registration | 34px 双圆 + 十字线，`opacity .5` | 图版旁或页脚 |
| 3 | 色条 color bar | 5 格 26×14：青/品/黄/黑/橙 | 页脚左，标注 "COLOR CONTROL" |
| 4 | 折线 fold line | 1px 虚线贯穿版面 + 竖排 "FOLD" | 装订/对折位（≈50% 或 63%） |
| 5 | 装订孔 binding | 13px 圆孔，内阴影 + 环形高光 | 贴页边，4 孔等距 |
| 6 | 贴纸 sticker | 旋转 -5°，硬阴影 `0 8px 16px -6px`，1px 描边 | 压在文字/图版边缘，**必须轻微越界** |
| 7 | 胶带 tape | 132×26，`clip-path` 撕边，半透明白，轻微旋转 | 压住贴纸或图版角 |
| 8 | 印章 stamp | 2px 橙描边，旋转 -11°，`mix-blend-mode:multiply`，`opacity .82` | 结论旁、图版下、页脚 |
| 9 | 涂抹条 redact | 墨色实条，hover 变橙底显字，`cursor:help` | 正文中的敏感数值/名词 |
| 10 | 边注 sidenote | 左侧 1px 竖线 + 10px 等宽，编号 `注 01` | 外侧栏，与正文同基线 |
| 11 | 脚注 footnote | 顶部 1px 线，9.5px 等宽，`sup` 用橙 | 版面底部 |
| 12 | 图注 figcap | `FIG.02` 橙色编号 + 双行说明（中/英） | 图版正下方，永不居中 |
| 13 | 校改栏 / 修订标记 | `REV.07` 章、删除线、`已阅` 印章 | 页眉右侧或正文侧边 |

工艺纪律：**标记在出血角、折线贯穿整版、装订孔贴边、贴纸压边**——位置错了就成了贴图，不是印刷。

## 5. 网点制版（图像的唯一合法形态）

```
格距 cell        3.6 – 5px
点径 radius      min(cell*0.63, sqrt(density) * cell*0.63)
抖动             ±0.16 cell（避免摩尔纹）
密度采样 figure  人体剪影 alpha × 0.72（不要 0.9，会糊成黑块）
             orbit  |sin(r*26)| × 径向衰减
             wave   |sin(v*7.2 + sin(u*3.4)*1.35)| × 边缘窗
             noise  伪随机 × 垂直渐变衰减
套准橙点         阈值 0.994，半径 × 0.34（1–2% 面积，像工艺溢出）
纸底             #efece2    墨 #151513    橙 #e9521c
显影             按行揭示，780ms，outCubic
```

- 图像**必须**带 `PL.01 / FIG.02` 编号与双行图注。
- 禁止：彩色照片、锐化、滤镜、圆角遮罩、发光。
- 网点密度不要拉满：留 15–25% 纸白，才有印刷味。

## 6. 油墨与色彩

- 单黑 + 专橙两色印刷。灰阶靠**网点密度**而不是灰色色值。
- 橙的四个合法用途：索引号 / 边注引线 / 印章 / 主数据或警告。**面积 ≤3%**。
- 套印错位：大字或图版可加 1px 橙/青鬼影（`text-shadow` 或双层绝对定位），仅在"图版/海报"级别使用，正文不用。
- 深色版 `#121211` 只做整版海报或封底，字色 `#f6f3eb`，橙保持同一支。

## 7. 声音：纸的声音

| 音 | 配方（WebAudio） | 出现的动作 |
|---|---|---|
| paper 翻页 | 噪声 + lowpass 2400→900Hz + highpass 480，0.42s，g .20 | 图版悬停、翻页、拆封 |
| stamp 盖章 | 两个低频正弦 140/96Hz，0.07s，g .30 | 印章、贴纸、确认落定 |
| tear 撕封 | 噪声 + lowpass 5200→700Hz + highpass 1200，0.5s | 拆封印章、撕胶带 |
| scratch 划擦 | 噪声 + bandpass 3600→1400Hz，0.19s | 涂抹条悬停、校改 |
| 电子族 | beep 1200Hz 短音 / step 1400Hz 12ms / alarm 880↔660Hz 四连 | 状态反馈、翻页落地、警告板 |

纪律：纸质音负责"物理动作"，电子音负责"系统状态"，两者不混用；同一动作只发一种主音。

## 8. 动效只做三件事

| 动作 | 实现 | 时长 |
|---|---|---|
| 压印 ink press | `opacity 0→1` + `translateY(9px)→0` + `blur(1.6px)→0`，outCubic | 720ms，元素间 60–80ms 错峰 |
| 制版 develop | 网点按行显影 | 780ms |
| 归档 file in | 翻页精确落位（逐帧重算目标），落地一声 beep；飞行期间静音 | 700ms |

禁止：bounce/elastic 泛滥、视差滚动堆叠、霓虹脉冲、无限循环的装饰动画。
重播规则：可重播的入场元素**完全离场后再进入**才重播一次；时钟、终端日志、交互接线类只初始化一次。

## 9. 六个版式模板

1. **封面**：机构大字（一页一次）+ 锁定行（SYNTHESIZE INFORMATION / ANALYSIS OS）+ 关键词行 + 右侧元数据表（CAT/CL/REV/PAGES/ISSUED/SIGN）+ 条码 + 贴纸 + 折线 + 色条/套准靶 + 页脚工艺说明。
2. **索引**：7 栏目录（编号 + 中文 + 英文 + 点线引导 + 页码）+ 摘要（双栏）+ 4 栏大描边数字（总量）+ 三条边注。
3. **正文跨栏**：7 栏双栏正文（首字下沉、涂抹条、脚注上标）+ 5 栏网点图版（FIG. 编号 + 双行图注 + 印章 + 胶带）+ 拉引句。
4. **数据板**：6 栏表格（caption + 1px 横线 + 等宽右对齐 + 橙色高亮行）+ 5 栏主读数（大数 + 单位上标 + 偏差）+ 跨 12 栏折线图（坐标轴、刻度、标注点、虚引线）。
5. **图版集**：4 栏说明 + 8 栏 2×2 网点图版（错位排列，hover 抬起 3px）+ 每图 `PL.xx` 与图注。
6. **海报/版权页**：整版黑 + 超大符号（＋−＝∞）+ 4 栏说明网格 + 印章 + 贴纸；版权页用 4 栏 colophon（出版/印刷/字体/声音）+ 出处清单 + 非官方声明 + 条码。

## 10. 自检清单（交付前逐条打勾）

- [ ] 去掉颜色后仍像档案（不是靠橙色撑场）
- [ ] 12 栏网格可叠加验证；无元素贴页边；间距是 8 的倍数
- [ ] 每版面只有一个大锚点；静区 ≥40%
- [ ] 橙面积 ≤3%，只用于索引/引线/印章/主数据
- [ ] 字号 ≥3 档且跨度 ≥10:1；大写带字距；数据等宽对齐
- [ ] 每版面印刷件 ≥3 种，位置符合工艺逻辑
- [ ] 图像是网点 + 编号 + 双行图注；无彩色照片
- [ ] 有版口：章节号 / 页码 / running head；有 ≥2 条注释
- [ ] 动效 700–900ms、outCubic、无 bounce；减少动态效果时可降级
- [ ] 音效需手势解锁；纸质音与电子音分工明确
- [ ] 移动端单栏降级不掉内容；`prefers-reduced-motion` 全静默
- [ ] 出处与许可声明在位（非官方同人、无原片采样）

## 11. 反例（出现任一即跑偏）

紫粉赛博渐变 · 发光边框 · 玻璃拟态卡片堆叠 · 全屏粒子 · emoji 图标 · 居中对称的三栏卡片 · 无字距的全大写标题 · 彩色照片配网点遮罩 · 每个元素都在动 · 橙色大面积铺底 · 圆角 16px 以上的"卡片化档案" · 只有动效没有版口（没有页码/编号/图注）。
