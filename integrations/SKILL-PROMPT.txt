【八条铁律】
1. 橙是唯一主强调（警告/当前/机械交互），荧光绿 lime 只做点缀
   （打字机光标/在线确认）；暗色场景强调换琥珀 #c5a16b、底 #11181b。
   色彩即状态，永不做装饰；灰阶只用四档（mute/faint/card/paper）。
2. 一切皆档案：编号（X-001）、日志行、进度条、取景框四角、机密涂抹条、
   双语字幕板、步骤指示器、套准点——内容装进档案框架再展示。
3. 动效是机械的不是弹性的：入场 outCubic（列表 stagger 100ms 错峰）、
   数字用里程计滚动、线条按进度绘制（stroke-dashoffset）、
   弹簧至多过冲一次（ζ≈0.45）；禁止 bounce/橡皮筋。
4. 文字入场 = 乱码解码（已解字符 + 尾部乱码，字符集
   "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789#%&*+=/<>"，
   乱码每 32ms 换批，尾部 3 位）或打字机（块状 lime 光标）；
   中文不用乱码，逐字淡入 + 上滑 0.25em，颜色从灰渐变到墨。
5. 排版：全大写英文标签宽字距 0.08~0.3em；章节代号负字距 -0.045em；
   等宽数字 font-variant-numeric:tabular-nums；页眉三行错峰出现
   （RHINE LAB / SYNTHESIZE INFORMATION / ANALYSIS OS）。
6. idle 永不静止但低频：旋转权限环、扫描线（~3% 不透明度横线）、
   呼吸（8s+13s 双周期错相、<3% 位移）、角落套准点闪烁。
7. 警告 = 橙括号条展开 + WARNING 大字距 + 日志逐行 + 4Hz 闪烁方块。
   深色板（#101112）只允许反白字 + 橙/lime 强调。
8. 音效一律 Web Audio 实时合成（振荡器+噪声+扫频），首次用户手势后
   才启动 AudioContext；禁止使用任何原片采样或外链音频。

【常用配方 · 直接照抄思路】
· 乱码解码：p 进度决定已解字符数，尾部乱码字符 = 字符集[floor(hash2(i,
  floor(t/32ms))*len)]；hash2(a,b)=frac(sin(a*157.31+b*113.97)*43758.5453)。
· 打字机：floor(p*n) 个字符 + <span> 实心 lime 光标块（宽 .55em 高 .95em）。
· 里程计：旧值→新值 outExpo 滚动，行高 0.95em，前导零。
· 分级入场：同一进度 p 的 q1=p*3, q2=p*3-0.5, q3=p*3-1.1 各自过 outCubic。
· 权限环：SVG 外弧正向转（86% 弧长，线宽 2），内弧反向，橙点轨道。
· 取景框四角：::before/::after 各画两角，16~18px，2px 线宽。
· 扫描线：repeating-linear-gradient(0deg, rgba(17,18,20,.035) 0 1px,
  transparent 1px 3px) 全屏覆盖层。
· 雷达扫描：conic-gradient(from 0deg, rgba(255,123,0,.3), transparent 70deg)
  圆形内旋转。
· HUD 框架：页眉（标题 700 / 副标宽字距 / ANALYSIS OS 右对齐）+ 左侧竖
  轨线 + lime 标记块 + 右下角页脚（24×5 横线 + POWERED BY RHINE LAB）+
  双语字幕板（黑底，中文 15px/字距2 + 英文 9px/字距3.2）。
· 布局基准 1920×1080：左轨线 x=429、页脚 y≈967、字幕 y≈1006。

【终端登录开场（高完成度作品标配）】
黑底全屏遮罩 → 三行文字逐字输入（打字音，行间隔约 80ms）→ SVG 权限环
扫描（扫频音）→ "PERMISSION AUTHORIZED"（确认音+和弦）→ 欢迎页
"WELCOME TO RHINE LAB.LLC."（.LLC. 用琥珀色）→ 白场闪切 → 淡出进入
正文。必须有多重兜底：onerror/超时强制放行/reduced-motion 跳过，
任何情况遮罩都要能关闭；提供 SKIP 按钮。

【音效最小配方（Web Audio）】
glass=3200Hz sine 20ms 快衰减；ui=640Hz square 45ms；thump=190Hz sine；
type=2200Hz square 8ms；beep=1200Hz sine 60ms；chime=[659,880] 双音；
alarm=[880,660]×3 交替；scan=400→1600Hz sawtooth 扫频 1.2s；
whoosh=白噪声+低通 3200→260 扫频。指数衰减到 0.0001，勿用线性。

【交付要求】
1. 单文件自包含 HTML（<!DOCTYPE html> 起，CSS/JS 全内联），双击可开。
2. 结构：HUD 页眉 → 章节代号 + 主标题（中文逐字滑入）→ 档案卡/数据行
   → 至少一种交互演示 → HUD 页脚 + 双语字幕板。
3. 全部文案双语（中文为主 + 英文全大写标签），伪数据用 X-001 /
   00042 / T-00:14:22 等前导零格式；机密内容用 ████ 涂抹或半调网点。
4. 页面语言 zh-CN；代码注释可中文；落款 "POWERED BY RHINE LAB —
   UNOFFICIAL FAN WORK, NOT AFFILIATED WITH HYPERGRYPH"。
5. 完成后自检：橙只做强调？入场机械感？至少一种档案元素？
   单文件可开？乱码/打字机至少一种？

【如果要 3D】
单独一个 HTML 页（不要与主页混合），用 three.js CDN（unpkg 失败换
jsdelivr），档案卡 = 圆角挤出盖板（transmission 玻璃）+ 深色内芯 +
橙色嵌片，通道距 5.2、选中沿镜头方向抽出、波浪按网格距离 80ms/格
传导（临界阻尼弹簧 ω=14）、呼吸 8s+13s 错相、ACES 色调映射 + PCFSoft
阴影 + PMREM 环境；加载失败显示降级提示。
